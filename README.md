# 🌍 APRESENTAÇÃO

Este repositório foi desenvolvido para reunir, documentar e organizar todas as atividades, pesquisas, exercícios, projetos e conhecimentos adquiridos durante a disciplina de Banco de Dados.

A proposta deste portfólio é servir como um registro completo da evolução acadêmica ao longo do curso, demonstrando o desenvolvimento de competências relacionadas ao armazenamento, modelagem, manipulação, análise e gerenciamento de informações em sistemas computacionais.

Os bancos de dados estão presentes em praticamente todas as áreas da sociedade moderna. Desde redes sociais até sistemas bancários, hospitais, escolas, plataformas de streaming, comércio eletrônico e inteligência artificial, praticamente toda tecnologia depende de estruturas capazes de armazenar e processar informações.

Por esse motivo, compreender os conceitos de Banco de Dados tornou-se uma das habilidades mais importantes para profissionais da área de Tecnologia da Informação.

A necessidade de armazenar informações acompanha a humanidade desde os primeiros registros escritos.

Ao longo do tempo, os métodos de armazenamento evoluíram significativamente:

### Antiguidade

- Tábuas de argila
- Papiros
- Pergaminhos

### Séculos XVIII e XIX

- Arquivos físicos
- Registros em papel
- Bibliotecas documentais

### Século XX

Com o surgimento dos computadores, tornou-se possível armazenar grandes quantidades de informações digitalmente.

# 🧠 CONCEITOS FUNDAMENTAIS

Um dado é um valor bruto sem interpretação.

Exemplos:

- 25
- João
- Azul
- 2026

## Informação

Informação é o resultado da organização dos dados.

Exemplo:

João possui 25 anos.

## Conhecimento

Conhecimento é a interpretação das informações para apoiar decisões.

# 🏗️ O QUE É UM BANCO DE DADOS?

Banco de Dados é um conjunto organizado de informações relacionadas entre si, armazenadas de forma estruturada para facilitar consultas, atualizações e gerenciamento.

# 🔗 RELACIONAMENTOS

## Um para Um (1:1)

Exemplo:

Pessoa ↔ RG

---

## Um para Muitos (1:N)

Exemplo:

Cliente ↔ Pedidos

---

## Muitos para Muitos (N:N)

Exemplo:

Alunos ↔ Cursos

# 🔑 CHAVES

## Chave Primária (PK)

Identifica registros de forma única.

Exemplo:

ID_Cliente

---

## Chave Estrangeira (FK)

Relaciona tabelas.

Exemplo:

ID_Cliente em Pedidos.
